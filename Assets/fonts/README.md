# Rock Salt TR

`rock-salt-tr.woff2`, Google Fonts'taki **Rock Salt** fontunun (© 2010 Font Diner, Inc DBA Sideshow,
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0)) Türkçe karakter eklenmiş hâlidir.

Orijinal fontta ş, Ş, ğ, Ğ ve İ yoktu. Bu harfler fontun kendi parçalarından birleşik glif olarak eklendi
(aksan kaydırmaları, font birimi cinsinden):

| Harf | Parçalar | x, y |
| --- | --- | --- |
| ş | s + cedilla | -40, 10 |
| Ş | S + cedilla | 100, -110 |
| ğ | g + breve | -10, -30 |
| Ğ | G + breve | 140, 260 |
| İ | I + dotaccent | 90, 260 |

Değişiklik: yukarıdaki beş glif eklendi, font adı "Rock Salt TR" yapıldı. Başka hiçbir şey değiştirilmedi.
